<a name="a-propos"></a>
<picture><source media="(prefers-color-scheme: light)" srcset="./assets/section-about-light.svg?v=5"/><img src="./assets/section-about-dark.svg?v=5" width="100%" alt="α′ Qui suis-je — Développeur Minecraft et web."/></picture>

Je développe pour Minecraft **Java** et **Bedrock** depuis plusieurs années : plugins Bukkit / Spigot et PocketMine-MP, mods Forge, systèmes de jeu complets. Côté web : panels d’administration, sites et API, du schéma de base de données jusqu’à la mise en prod.

Aujourd’hui je passe en **freelance** et j’ouvre mon agenda à de nouveaux projets. Chaque projet porte le nom d’une divinité grecque, a son site, sa couleur, et sa doc sur [Chronos](https://docs.salks.me).
